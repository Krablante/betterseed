# BetterSeed v2026.09.22-1

Fixes the reproduced crash when returning from View edits with a large masked
filter stack. Based on the last accepted BetterSeed mod, not a different Snapseed
release.

**One-time reinstall required for April builds:** the original signing key is
unavailable, so this release starts a new permanent signing identity. Save and
back up your editable `.snpsd` projects **before uninstalling the old BetterSeed**.
Uninstalling deletes private app data and unsaved work. Read the
[migration instructions](https://github.com/Krablante/betterseed/blob/v2026.09.22-1/docs/install.md#upgrading-from-april-2026-releases).

- Removes duplicate history completion and the temporary-file state handoff
  consumed by two result handlers.
- Preserves mask detail and the existing native renderer; no image downsampling
  or brush simplification was introduced.
- Fixes history Undo and preserves the entry state for Discard after recreation.
- Adds a small, checksum-pinned patch/build path for maintainable future releases.

Manually verified using one Android emulator: reproduced the old failure with a
128,490-byte filter-state payload; checked toolbar/system Back, Copy/Replace,
mask re-edit, rotation/Discard, delete/Undo/Redo, editable projects and a
5152×3864 full-resolution JPEG export. See [verification details](https://github.com/Krablante/betterseed/blob/v2026.09.22-1/docs/verification-2026-09-22.md).
This is not a claim that every possible large-image memory failure is fixed.
